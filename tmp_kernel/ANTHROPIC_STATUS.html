03. NCU상 이미 한계인가

GPU 전체 사용률 하나로 판단하지 않는다. 아래는 각 profile에서 가장 오래 걸린 kernel의 지표다.

해석 기준

LayerNorm: L768의 HBM 대역폭 85.8–89.8%. 독립 LN 재개발 우선순위는 낮다.

TriMul / attention / Transition: 모두 roofline에 도달했다고 볼 근거는 없다. 원본을 채택해도 분석·개선 여지는 남는다.

지표는 각 sustained peak 대비 비율이다. 낮은 tensor 비율이 곧 특정 배속의 여유를 뜻하지 않는다. Softmax·SFU·의존성·launch 비용 등을 추가로 구분해야 한다. NCU 시간은 Graph latency와 별도이며 clock/cache 강제 제어 없이 측정했다.

원본 K1/K3 학습 연결 · backward는 검증용

TriMul 원본 K1/K3를 학습 모듈에 연결했다. 이 기준선의 backward는 PyTorch 재계산/cuBLAS이며 아직 느리다. 원본 low-level 추론 API와 구분한다.

이전 학습 커널은 비교 기준으로 남아 있지만, 새 원본 추론 경로에 backward가 연결됐다는 뜻은 아니다.

원본 전체 forward 학습 연결 · 빠른 backward 남음

실측 당시 분석 전용 GPU 2개를 사용했고 완료 후 반환했다. 이 페이지는 현재 GPU 잡 상태를 실시간 조회하지 않는다.

06. 검증 근거와 전체 후보

CPU adapter 11개 + B=2 모듈 검사 10개 통과. upstream GPU 테스트 151개 통과, cache 필드 문제 1개는 fresh cache에서 통과. 6 skip / 18 제외는 별도 기록했다.

출력 상대 RMS 최대 0.538%, residual을 뺀 update 상대 RMS 최대 2.182%. 검사 상한은 3%이며 biological accuracy 검증이나 bitwise exact 인증은 아니다.

Gather는 indices를 한 번 정렬하고 ensure_sorted=False로 Graph capture를 검증했다. Atom-window는 FP32 IEEE와 원본 기본 tf32rn을 별도로 측정했다. 후보별 조건은 아래 원본 JSON에서 확인할 수 있다.
