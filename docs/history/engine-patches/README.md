# Engine 1.x / 2.1 patch stack (historical)

These patches and SHA-256 manifests edited an installed miniworld-engine before
the consolidated engine main. They moved here from `patches/` on 2026-09-30.
miniworld-engine v2.2.0 removed the CuTe DSL kernels and MiniWorld removed the
patch and cache-publication tools, so nothing applies them any more. They remain
as the record the linked docs cite. The FoldBench adapter patch still used by
MiniWorld stays in `patches/dependencies/`.
